# Vue 2 从 0 到精通 · 学习版

> **这套文档写给谁**：完全没有前端基础，或者能看懂 HTML 但一打开 `.vue` 文件就懵的读者。
>
> **目标**：从「不认识 Vue」走到「能独立读懂本项目所有页面、能照着改、能讲清原理、能应对 Vue 2 面试」。
>
> **不假设你会什么**：HTML/CSS/JavaScript 都从最小必要集讲起；每个 Vue 概念先给一个能单独运行的小例子，再回到本项目的真实代码里看它怎么用。

## 二、学习路线：四个阶段

```
阶段一：看得懂（第 0~3 章）
  HTML/CSS/JS 最小基础 → 第一个 Vue 应用 → 模板语法 → 实例选项与生命周期
  达标：能独立写出一个计数器、待办列表、带表单校验的小页面

阶段二：读得懂项目（第 4~7 章）
  组件化 → Vue Router → Vuex → 工程化与请求层
  达标：能说清一个页面从路由进入、拉数据、渲染表格、弹窗提交的全过程

阶段三：改得动、写得出（第 8~9 章）
  手写一个完整 CRUD 页面 → 精读项目两个真实页面
  达标：能在项目里新增一个菜单页、加一列、改一个接口

阶段四：讲得清（第 10~12 章 + 附录）
  响应式原理 / 虚拟 DOM / nextTick / keep-alive → 常见坑 → 面试题库
  达标：面试被追问「为什么数据变了页面会变」能讲到 getter/setter 和 Watcher
```

**时间建议**（按每天 2~3 小时）：

| 阶段 | 内容 | 建议天数 |
|---|---|---|
| 一 | 第 0~3 章 | 5~7 天 |
| 二 | 第 4~7 章 | 6~8 天 |
| 三 | 第 8~9 章 | 3~5 天 |
| 四 | 第 10~12 章 | 4~6 天 |

不要跳过阶段一直接读项目。Vue 的模板语法和「数据驱动」思维没建立起来，读项目只会变成抄代码。

## 四、怎么读：每章固定五段

1. **这一章解决什么问题**：先给场景，不先给语法。
2. **最小可运行例子**：一段能单独跑起来的代码（多数用 CDN 版 Vue，不需要装环境）。
3. **回到本项目**：同样的知识点在 `zxcm-ui` 里哪一行、为什么这么写。
4. **动手练习**：3~5 个小练习，带验收标准。
5. **自测清单**：能答上来才算过关。

> **定位约定**：前端文件写相对 `zxcm-ui/` 的路径 + 行号，例如 `src/views/system/position/index.vue:185`；Vue 官方文档用外部链接。

## 五、版本坐标（很重要）

本项目是 **RuoYi-Vue-Plus 4.x 血统**，前端版本（`zxcm-ui/package.json`）：

| 依赖 | 版本 | package.json 行号 |
|---|---|---|
| Vue | **2.6.12** | `:64` |
| Vue Router | **3.4.9** | `:69` |
| Vuex | **3.6.0** | `:72` |
| Element UI | 2.15.6 | `:47` |
| axios | 0.24.0 | `:41` |
| @vue/cli-service | 4.4.6 | `:78` |

**红线**：

- Vue 2 和 Vue 3 的 API 差异很大（`new Vue()` vs `createApp()`、`Vuex` vs `Pinia`、`filters` 被移除等）。网上很多教程是 Vue 3，**先确认版本再抄代码**。
- Vue Router 2/3 用 `new Router()`，Vue Router 4 用 `createRouter()`。
- Vuex 3 用 `new Vuex.Store()`，Vuex 4 同名但配套 Vue 3；Pinia 是另一套东西，本项目没用。
- 本文所有「项目案例」都以本仓库 `zxcm-ui` 为准，不保证适用于其它版本。

## 七、开始之前：你需要准备什么

**只要三样东西**：

1. 一个浏览器（Chrome/Edge），会按 F12 打开开发者工具；
2. 一个编辑器（VS Code 或 WebStorm）；
3. 本仓库能跑起来（最少把 `zxcm-ui` 跑起来；第 1~2 章的小例子不需要跑项目）。

**运行本项目前端**（详见[第 7 章](第7章-工程化与请求层.md)）：

```bash
cd zxcm-ui
npm install
npm run dev
```

> 本机 npm 命令可能需要先把 Node 路径放到 PATH 前面（见项目环境笔记）。跑不起来不影响第 0~2 章，但第 8~9 章必须能跑。

**学习工具**：

- 浏览器 F12 → Console（看日志/报错）、Network（看请求）、Sources（打断点）；
- 安装 Vue Devtools 扩展，能直接看组件树、data、Vuex 状态。

## 八、怎么用这套文档配合项目

```
读一章（概念 + 小例子）
   ↓
打开项目对应文件，按行号对照
   ↓
改一行，保存，看页面变化（热更新）
   ↓
改回去 / 做练习
   ↓
用自己的话讲一遍（录音或写下来）
   ↓
过本章自测清单
```

**一个非常重要的习惯**：每读一个项目文件，先在浏览器里找到它对应的页面，点一遍页面上的按钮，再看代码。**先有界面行为，再看代码实现**，比从代码猜界面快十倍。

## 九、学完之后你应该能回答的问题

1. 为什么 `this.list = res.rows` 之后表格会自动刷新？
2. `v-if` 和 `v-show` 有什么区别？项目里哪里用了哪个？
3. `computed` 和 `watch` 分别适合什么场景？
4. 父组件怎么把数据传给子组件？子组件怎么通知父组件？
5. `.sync` 本质是什么？
6. `created` 和 `mounted` 的区别？为什么项目里拉数据大多写在 `created`？
7. 路由守卫 `beforeEach` 里为什么能拦住未登录用户？
8. 后端的菜单是怎么变成前端路由的？
9. Vuex 的 `commit` 和 `dispatch` 有什么区别？
10. 为什么修改数组下标/对象新增属性有时不触发更新？怎么解决？
11. `nextTick` 是干什么的？
12. `key` 在 `v-for` 里有什么用？

如果这些问题你都能结合本项目代码回答，这个项目的前端部分就真正属于你了。
