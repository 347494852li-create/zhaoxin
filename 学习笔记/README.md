## 🎯 三条必须提前知道的事实

### ① 这是 SPA + 动态路由

- 整个网站**只有一个 HTML**，所有页面都是 JS 渲染出来的
- **业务页面的路由不写在前端代码里**，登录后从后端 `sys_menu` 表拿
- 所以：**数据库里加一条菜单，前端才会多一个页面**

### ② 前端权限只是「界面美化」，不是安全防线

| 层 | 控制什么 | 能绕过吗 |
|---|---|---|
| 路由级 | 能不能打开页面 | ✅ 改 URL / 直接调接口 |
| 菜单级 | 侧边栏显示什么 | ✅ 同上 |
| 按钮级 | 页面显示什么按钮 | ✅ 改 DOM |

**真正的防线是后端的 `@SaCheckPermission` 注解。**

### ③ 三个最容易踩的坑

```javascript
// 坑 1：头名不是 Authorization
config.headers['token'] = 'Bearer ' + getToken()   // ✅

// 坑 2：=== false 不能写成 !isToken
const isToken = (config.headers || {}).isToken === false   // ✅
// 写成 !undefined 会变 true → 所有请求不带 token → 全站 401

// 坑 3：config.params 必须清空
config.params = {}    // 不清空 axios 会再拼一次 → ?a=1&a=1
```
