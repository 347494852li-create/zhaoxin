# 8.1 需求：做一个"演示管理"

## 功能清单

| 功能 | 说明 |
|---|---|
| 列表 | 分页显示，支持按名称搜索 |
| 新增 | 弹窗输入名称、编码、状态 |
| 修改 | 点"修改"弹出同一个窗，带数据 |
| 删除 | 单个删除 + 批量删除（二次确认） |
| 权限 | 没权限的用户看不到按钮 |

## 数据表

```sql
CREATE TABLE demo (
  id          bigint(20)   NOT NULL AUTO_INCREMENT COMMENT '主键',
  name        varchar(100) NOT NULL COMMENT '名称',
  code        varchar(50)  NOT NULL COMMENT '编码',
  status      char(1)      DEFAULT '0' COMMENT '状态（0正常 1停用）',
  create_by   varchar(64)  DEFAULT '' COMMENT '创建者',
  create_time datetime     DEFAULT NULL COMMENT '创建时间',
  update_by   varchar(64)  DEFAULT '' COMMENT '更新者',
  update_time datetime     DEFAULT NULL COMMENT '更新时间',
  del_flag    char(1)      DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='演示表';
```

**⭐ 注意 `del_flag`**：这是 RuoYi 的逻辑删除字段。
`@TableLogic` 会自动把 `DELETE` 语句变成 `UPDATE ... SET del_flag='2'`。

# 8.3 步骤 1：建 api 文件

**新建文件**：`src/api/demo/index.js`

```javascript
import request from '@/utils/request'

// 查询演示列表
export function listDemo(query) {
  return request({
    url: '/demo/list',
    method: 'get',
    params: query                    // ★ GET 用 params
  })
}

// 查询演示详细
export function getDemo(id) {
  return request({
    url: '/demo/' + id,
    method: 'get'
  })
}

// 新增演示
export function addDemo(data) {
  return request({
    url: '/demo',
    method: 'post',
    data: data                       // ★ POST 用 data
  })
}

// 修改演示
export function updateDemo(data) {
  return request({
    url: '/demo',
    method: 'put',
    data: data
  })
}

// 删除演示
export function delDemo(id) {
  return request({
    url: '/demo/' + id,
    method: 'delete'
  })
}
```

## ⭐ 这份文件的设计要点

| 要点 | 说明 |
|---|---|
| **文件名和模块名对应** | `demo/index.js` ↔ 页面 `demo/index.vue` |
| **每个函数一个接口** | 不要合并 |
| **URL 用 RESTful 风格** | 新增/修改同 URL，靠 method 区分 |
| **GET 用 `params`，POST/PUT 用 `data`** | ⚠️ 搞反了参数传不过去 |

## ⭐ 和后端的对应关系

| 前端函数 | method + URL | 后端注解 |
|---|---|---|
| `listDemo` | GET `/demo/list` | `@GetMapping("/list")` |
| `getDemo` | GET `/demo/{id}` | `@GetMapping("/{id}")` |
| `addDemo` | POST `/demo` | `@PostMapping` |
| `updateDemo` | PUT `/demo` | `@PutMapping` |
| `delDemo` | DELETE `/demo/{id}` | `@DeleteMapping("/{ids}")` |

**⭐ 记住这个规律**：前端 `url` + `method` = 后端类上的 `@RequestMapping` + 方法上的注解。

# 8.4 步骤 2：建列表页

**新建文件**：`src/views/demo/index.vue`

## 完整代码

```vue
<template>
  <div class="app-container">
    <!-- ==================== ① 搜索区 ==================== -->
    <el-form
      v-show="showSearch"
      ref="queryForm"
      :model="queryParams"

          placeholder="请输入编码"

          @keyup.enter.native="handleQuery"
        />
      </el-form-item>
      <el-form-item>
        <el-button type="primary" icon="el-icon-search" size="mini" @click="handleQuery">搜索</el-button>
        <el-button icon="el-icon-refresh" size="mini" @click="resetQuery">重置</el-button>
      </el-form-item>
    </el-form>

    <!-- ==================== ② 工具栏 ==================== -->
    <el-row :gutter="10" class="mb8">
      <el-col :span="1.5">
        <el-button
          v-hasPermi="['demo:add']"
          type="primary"
          plain
          icon="el-icon-plus"
          size="mini"
          @click="handleAdd"
        >新增</el-button>
      </el-col>
      <el-col :span="1.5">
        <el-button
          v-hasPermi="['demo:remove']"
          type="danger"
          plain
          icon="el-icon-delete"
          size="mini"
          :disabled="multiple"
          @click="handleDelete"
        >删除</el-button>
      </el-col>
      <right-toolbar :showSearch.sync="showSearch" @queryTable="getList" />
    </el-row>

    <!-- ==================== ③ 表格 ==================== -->
    <el-table
      v-loading="loading"
      :data="demoList"
      @selection-change="handleSelectionChange"

      <el-table-column type="selection" width="55" align="center" />
      <el-table-column label="名称" prop="name" :show-overflow-tooltip="true" />
      <el-table-column label="编码" prop="code" />
      <el-table-column label="状态" prop="status" width="100">
        <template slot-scope="scope">
          <el-tag v-if="scope.row.status === '0'" type="success">正常</el-tag>
          <el-tag v-else type="danger">停用</el-tag>
        </template>
      </el-table-column>
      <el-table-column label="创建时间" prop="createTime" width="180" />
      <el-table-column label="操作" width="160" class-name="small-padding fixed-width">
        <template slot-scope="scope">
          <el-button
            v-hasPermi="['demo:edit']"
            size="mini"
            type="text"
            icon="el-icon-edit"
            @click="handleUpdate(scope.row)"
          >修改</el-button>
          <el-button
            v-hasPermi="['demo:remove']"
            size="mini"
            type="text"
            icon="el-icon-delete"
            @click="handleDelete(scope.row)"
          >删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- ==================== ④ 分页 ==================== -->
    <pagination
      v-show="total > 0"
      :total="total"
      :page.sync="queryParams.pageNum"
      :limit.sync="queryParams.pageSize"
      @pagination="getList"
    />

    <!-- ==================== ⑤ 新增/编辑弹窗 ==================== -->
    <edit-dialog ref="editDialog" @ok="getList" />
  </div>
</template>

<script>
import { listDemo, delDemo } from '@/api/demo'
import EditDialog from './edit.vue'

export default {
  name: 'DemoIndex',
  components: { EditDialog },

  data() {
    return {
      loading: true,              // 表格加载中
      showSearch: true,           // 搜索区显示
      demoList: [],               // 列表数据
      total: 0,                   // 总条数
      ids: [],                    // 选中的 id 数组
      single: true,               // 非单个禁用
      multiple: true,             // 非多个禁用
      queryParams: {              // 查询参数
        pageNum: 1,
        pageSize: 10,
        name: undefined,
        code: undefined
      }
    }
  },

  created() {
    this.getList()
  },

  methods: {
    /** 查询列表 */
    getList() {
      this.loading = true
      listDemo(this.queryParams).then(response => {
        this.demoList = response.rows
        this.total = response.total
        this.loading = false
      })
    },

    /** 搜索 */
    handleQuery() {
      this.queryParams.pageNum = 1
      this.getList()
    },

    /** 重置 */
    resetQuery() {
      this.resetForm('queryForm')
      this.handleQuery()
    },

    /** 多选 */
    handleSelectionChange(selection) {
      this.ids = selection.map(item => item.id)
      this.single = selection.length !== 1
      this.multiple = !selection.length
    },

    /** 新增 */
    handleAdd() {
      this.$refs.editDialog.open()
    },

    /** 修改 */
    handleUpdate(row) {
      this.$refs.editDialog.open(row.id)
    },

    /** 删除 */
    handleDelete(row) {
      const ids = row.id || this.ids
      this.$modal
        .confirm('是否确认删除选中的数据项？')
        .then(() => {
          this.loading = true
          return delDemo(ids)
        })
        .then(() => {
          this.loading = false
          this.getList()
          this.$modal.msgSuccess('删除成功')
        })
        .finally(() => {
          this.loading = false
        })
    }
  }
}
</script>
```

## 逐块讲解

### ① 搜索区

```html
<el-form
  v-show="showSearch"                <!-- 可折叠 -->
  ref="queryForm"                    <!-- 给 resetForm 用 -->
  :model="queryParams"               <!-- 绑定数据对象 -->
  :inline="true"                     <!-- 行内布局 -->
  label-width="68px"
>
  <el-form-item label="名称" prop="name">
    <el-input
      v-model="queryParams.name"     <!-- 双向绑定 -->
      clearable                       <!-- 显示清空按钮 -->
      @keyup.enter.native="handleQuery"  <!-- 回车搜索 -->
    />
  </el-form-item>
```

**⭐ `ref="queryForm"` 的作用**：让 `this.resetForm('queryForm')` 能拿到这个表单并清空它。

**`resetForm` 的实现**（`src/utils/ruoyi.js`）：

```javascript
export function resetForm(refName) {
  if (this.$refs[refName]) {
    this.$refs[refName].resetFields()
  }
}
```

**注意它是挂在 `Vue.prototype` 上的**（`main.js:77`），所以能直接 `this.resetForm(...)`。

### ② 工具栏 + 权限

```html
<el-button
  v-hasPermi="['demo:add']"          <!-- ★ 没权限就不显示 -->
  @click="handleAdd"
>新增</el-button>

<el-button
  v-hasPermi="['demo:remove']"
  :disabled="multiple"                <!-- ★ 没选中时禁用 -->
  @click="handleDelete"
>删除</el-button>
```

**⭐ `:disabled="multiple"`** 的逻辑：

```javascript
multiple: true      // 初始 true → 禁用
// 选中后
handleSelectionChange(selection) {
  this.multiple = !selection.length   // 有选中 → false → 启用
}
```

**语义有点绕**：变量名 `multiple` 实际表示"**是否禁用**"。

RuoYi 的命名：`single` = 非单个时禁用，`multiple` = 非多个时禁用。

### ③ 表格 + 插槽

```html
<el-table
  v-loading="loading"
  :data="demoList"
  @selection-change="handleSelectionChange"
>
  <el-table-column label="状态" prop="status">
    <template slot-scope="scope">
      <el-tag v-if="scope.row.status === '0'" type="success">正常</el-tag>
      <el-tag v-else type="danger">停用</el-tag>
    </template>
  </el-table-column>
```

**⭐ `slot-scope="scope"` 的 `scope.row` 是当前行数据。**

**为什么要插槽？** 因为"状态"字段存的是 `'0'`/`'1'`，
要显示成 `正常`/`停用` 的标签，不能用 `prop` 直接显示。

**⭐ 另一种写法**（用项目的 `dict-tag` 全局组件）：

```html
<el-table-column label="状态" prop="status">
  <template slot-scope="scope">
    <dict-tag :options="dict.type.sys_normal_disable" :value="scope.row.status" />
  </template>
</el-table-column>
```

配合 `data()` 里：

```javascript
export default {
  dicts: ['sys_normal_disable'],     // ★ 声明用哪个字典
}
```

**`dicts` 是 RuoYi 的自定义选项**（在 `src/components/DictData` 里实现），
会自动去后端加载字典数据，存到 `this.dict`。

### ④ 分页

```html
<pagination
  v-show="total > 0"
  :total="total"
  :page.sync="queryParams.pageNum"
  :limit.sync="queryParams.pageSize"
  @pagination="getList"
/>
```

**`<pagination>` 是全局组件**（`main.js` 里注册的 13 个之一），**不用 import**。

| 属性 | 含义 |
|---|---|
| `:total` | 总条数 |
| `:page.sync` | 当前页码（`.sync` 让子组件能改父组件的值） |
| `:limit.sync` | 每页条数 |
| `@pagination` | 页码变化时触发（重新查） |

**⭐ `.sync` 修饰符**：本质是"子组件 `$emit('update:page', newVal)` → 父组件自动更新 `queryParams.pageNum`"。

### ⑤ 弹窗组件

```html
<edit-dialog ref="editDialog" @ok="getList" />
```

- `ref="editDialog"` → 父组件能用 `this.$refs.editDialog.open()` 调它方法
- `@ok="getList"` → 子组件保存成功后 `$emit('ok')` → 父组件刷新列表

# 8.5 步骤 3：建新增/编辑弹窗

**新建文件**：`src/views/demo/edit.vue`

```vue
<template>
  <el-dialog
    :title="title"
    :visible.sync="visible"
    width="500px"
    append-to-body
    :close-on-click-modal="false"
  >
    <el-form ref="form" :model="form" :rules="rules" label-width="80px">
      <el-form-item label="名称" prop="name">
        <el-input v-model="form.name" placeholder="请输入名称" />
      </el-form-item>
      <el-form-item label="编码" prop="code">
        <el-input v-model="form.code" placeholder="请输入编码" />
      </el-form-item>
      <el-form-item label="状态" prop="status">
        <el-radio-group v-model="form.status">
          <el-radio label="0">正常</el-radio>
          <el-radio label="1">停用</el-radio>
        </el-radio-group>
      </el-form-item>
    </el-form>

    <div slot="footer" class="dialog-footer">
      <el-button type="primary" @click="submitForm">确 定</el-button>
      <el-button @click="cancel">取 消</el-button>
    </div>
  </el-dialog>
</template>

<script>
import { getDemo, addDemo, updateDemo } from '@/api/demo'

export default {
  name: 'DemoEdit',
  data() {
    return {
      visible: false,
      title: '',
      form: {},
      rules: {
        name: [
          { required: true, message: '名称不能为空', trigger: 'blur' }
        ],
        code: [
          { required: true, message: '编码不能为空', trigger: 'blur' }
        ]
      }
    }
  },
  methods: {
    /** 打开弹窗（id 为空 = 新增，有值 = 修改） */
    open(id) {
      this.reset()
      this.visible = true
      if (id) {
        this.title = '修改演示'
        getDemo(id).then(response => {
          this.form = response.data
        })
      } else {
        this.title = '新增演示'
      }
    },

    /** 重置表单 */
    reset() {
      this.form = {
        id: undefined,
        name: undefined,
        code: undefined,
        status: '0'
      }
      // ⚠️ 需要等 DOM 更新后再 resetFields，否则会报错
      this.$nextTick(() => {
        if (this.$refs.form) {
          this.$refs.form.resetFields()
        }
      })
    },

    /** 取消 */
    cancel() {
      this.visible = false
      this.reset()
    },

    /** 提交 */
    submitForm() {
      this.$refs.form.validate(valid => {
        if (!valid) return

        if (this.form.id) {
          updateDemo(this.form).then(() => {
            this.$modal.msgSuccess('修改成功')
            this.visible = false
            this.$emit('ok')              // ★ 通知父组件刷新
          })
        } else {
          addDemo(this.form).then(() => {
            this.$modal.msgSuccess('新增成功')
            this.visible = false
            this.$emit('ok')
          })
        }
      })
    }
  }
}
</script>
```

## ⭐ 这个弹窗的模式（RuoYi 的标准写法）

| 要点 | 说明 |
|---|---|
| `:visible.sync="visible"` | 弹窗显示/隐藏由父组件的 `visible` 控制 |
| `open(id)` | 父组件调这个方法打开弹窗。`id` 有值 = 修改，没值 = 新增 |
| `this.reset()` | 每次打开前先清空，避免上次的数据残留 |
| `$emit('ok')` | 保存成功后通知父组件刷新列表 |
| `append-to-body` | 弹窗挂到 `body` 上（避免被父元素 `overflow` 裁剪） |
| `:close-on-click-modal="false"` | 点遮罩不关闭（防止误关丢数据） |

## ⚠️ 为什么 `reset()` 里要 `$nextTick`

```javascript
reset() {
  this.form = { ... }
  this.$nextTick(() => {
    if (this.$refs.form) {
      this.$refs.form.resetFields()     // ← 必须等 DOM 更新
    }
  })
}
```

**问题**：改了 `this.form` 之后，`resetFields()` 需要表单**已经渲染**。

**如果用 `v-if` 控制弹窗**，弹窗内容在打开前不存在，`this.$refs.form` 是 `undefined`。

**`$nextTick` 保证 DOM 更新完成后再执行。**

**⚠️ 项目里有些地方没加 `$nextTick` 会报错**：

```
Cannot read property 'resetFields' of undefined
```

# 查有没有菜单缓存

## Controller 参考代码

```java
@Validated
@Api(value = "演示管理控制器", tags = {"演示管理"})
@RequiredArgsConstructor
@RestController
@RequestMapping("/demo")
public class DemoController extends BaseController {

    private final IDemoService iDemoService;

    @ApiOperation("查询演示列表")
    @SaCheckPermission("demo:list")                       // ★ 权限校验
    @GetMapping("/list")
    public TableDataInfo<DemoVo> list(DemoBo bo, PageQuery pageQuery) {
        return iDemoService.queryPageList(bo, pageQuery);
    }

    @ApiOperation("获取演示详细信息")
    @SaCheckPermission("demo:query")
    @GetMapping("/{id}")
    public R<DemoVo> getInfo(@PathVariable Long id) {
        return R.ok(iDemoService.queryById(id));
    }

    @ApiOperation("新增演示")
    @SaCheckPermission("demo:add")
    @Log(title = "演示", businessType = BusinessType.INSERT)
    @RepeatSubmit()                                        // ★ 防重复提交
    @PostMapping
    public R<Void> add(@Validated(AddGroup.class) @RequestBody DemoBo bo) {
        return toAjax(iDemoService.insertByBo(bo));
    }

    @ApiOperation("修改演示")
    @SaCheckPermission("demo:edit")
    @Log(title = "演示", businessType = BusinessType.UPDATE)
    @RepeatSubmit()
    @PutMapping
    public R<Void> edit(@Validated(EditGroup.class) @RequestBody DemoBo bo) {
        return toAjax(iDemoService.updateByBo(bo));
    }

    @ApiOperation("删除演示")
    @SaCheckPermission("demo:remove")
    @Log(title = "演示", businessType = BusinessType.DELETE)
    @DeleteMapping("/{ids}")
    public R<Void> remove(@PathVariable Long[] ids) {
        return toAjax(iDemoService.deleteWithValidByIds(Arrays.asList(ids), true));
    }
}
```

## ⭐ 四个关键注解（每个接口都要有）

| 注解 | 作用 | 漏了会怎样 |
|---|---|---|
| `@SaCheckPermission("demo:xxx")` | **权限校验（防线）** | ⚠️ **任何人能调**（安全漏洞） |
| `@Log(title=..., businessType=...)` | 记操作日志 | 操作日志里没记录 |
| `@RepeatSubmit()` | 防重复提交（Redis 锁） | 可能重复插入数据 |
| `@ApiOperation(...)` | 接口文档描述 | 文档里看不到说明 |

**⭐ `@SaCheckPermission` 的字符串必须和数据库 `sys_menu.perms` 完全一致。**

# 8.11 常见问题

## Q1：菜单加了但不显示

**排查顺序**：

```
① 数据库查
   SELECT * FROM sys_menu WHERE menu_name='演示管理';
   → 没有？说明 SQL 没执行成功

② 查 visible
   → 是 '1'？改成 '0'

③ 查角色分配
   SELECT * FROM sys_role_menu WHERE menu_id=<那个id>;
   → 没有？说明没分配

④ 查 /getRouters 的 Response
   → 没有？说明后端没查出来

⑤ Ctrl+F5 强刷
   → 菜单是登录时拉的，不刷新看不到
```

## Q2：点进去白屏

**F12 → Console 看报错**：

| 报错 | 原因 |
|---|---|
| `Cannot find module '@/views/demo/index'` | 文件不存在或路径错 |
| `Cannot read property 'xxx' of undefined` | 组件里访问了不存在的字段 |
| `Unexpected token` | 语法错误 |

## Q3：接口 404

```
① 后端重启了吗？
② controller 的 @RequestMapping("/demo") 对吗？
③ 前端 url: '/demo/list' 对吗？
④ F12 → Network → 看实际请求的 URL
```

## Q4：接口 403

```
→ 说明 @SaCheckPermission 拦住了
→ 检查数据库 sys_menu.perms 和注解字符串是否一致
→ 检查当前用户是否分配了这个权限
→ 重新登录（让权限刷新）
```

## Q5：新增报 400

```
→ 后端 @Validated 校验没通过
→ F12 → Network → Response 看具体哪个字段
→ 常见：@NotBlank 的字段前端没传
```

## Q6：数据不对（列表是空的）

```
① 数据库表里有数据吗？
   SELECT COUNT(*) FROM demo WHERE del_flag='0';
② 后端 SQL 有 where del_flag='0' 吗？（@TableLogic 自动加）
③ F12 → Network → /demo/list 的 Response 里 rows 是空的？
   → 说明后端查询没结果
```

## Q7：改了前端代码不生效

```
→ 热更新可能失效
→ Ctrl+F5 强刷
→ 或者 Ctrl+C 重启 npm run dev
```

# 本章自测

1. 加一个新页面，前端要建几个文件？
2. `api` 文件里 GET 和 POST 分别用 `params` 还是 `data`？
3. `v-hasPermi` 里的权限码要和哪里保持一致？
4. `sys_menu` 里按钮类型的 `menu_type` 是什么？`path` 和 `component` 填什么？
5. 为什么 `resetForm('queryForm')` 能清空表单？
6. `<pagination>` 为什么不用 import？
7. 弹窗组件的 `open(id)` 方法，`id` 为空和有值分别是什么含义？
8. 为什么弹窗的 `reset()` 里要 `$nextTick`？
9. 无权限用户看不到按钮，但直接调接口能成功，说明什么？
10. 加了菜单为什么不重启看不到？

<details>
<summary>答案</summary>

1. **3 个**：`api/demo/index.js`、`views/demo/index.vue`、`views/demo/edit.vue`
2. GET 用 `params`（拼 URL），POST/PUT 用 `data`（放请求体）
3. 和后端 `@SaCheckPermission("demo:add")` 里的字符串、数据库 `sys_menu.perms` 的值**三处一致**
4. `menu_type='F'`；`path` 和 `component` 都填**空字符串**
5. 因为 `resetForm` 是挂在 `Vue.prototype` 上的全局方法，内部用 `this.$refs[refName].resetFields()`
6. 因为 `<pagination>` 是 `main.js` 里 `Vue.component("Pagination", Pagination)` **全局注册**的
7. `id` 为空 = **新增**；`id` 有值 = **修改**（会先去查详情）
8. 因为改 `this.form` 后 DOM 还没更新，`this.$refs.form` 可能还是 `undefined`（尤其用 `v-if` 控制弹窗时）
9. **后端漏了 `@SaCheckPermission` 注解** —— 这是**安全漏洞**，前端权限只是界面控制
10. 因为菜单是**登录时**从 `/getRouters` 拉的，`roles` 已有值就不会重新拉。要刷新页面清空 store
</details>
