# 12.1 任务说明：做一个"供应商管理"

## 需求

**做一个供应商管理模块**，含：

| 功能 | 要求 |
|---|---|
| 列表 | 分页显示，支持按"供应商名称"和"联系人"搜索 |
| 新增 | 弹窗输入：名称、统一社会信用代码、联系人、电话、状态 |
| 修改 | 点"修改"带出数据 |
| 删除 | 单个 + 批量，都要二次确认 |
| 导出 | 导出 Excel（可选，进阶） |
| 权限 | 4 个权限码：`supplier:list/query/add/edit/remove` |

## 数据表设计

**自己设计 `supplier` 表**（参考第 8 章的 `demo` 表）：

**必含字段**：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigint | 主键，自增 |
| `supplier_name` | varchar | 供应商名称 |
| `credit_code` | varchar | 统一社会信用代码 |
| `contact_person` | varchar | 联系人 |
| `contact_phone` | varchar | 联系电话 |
| `status` | char(1) | 状态（0正常 1停用） |
| `create_by` / `create_time` | | 创建信息 |
| `update_by` / `update_time` | | 更新信息 |
| `del_flag` | char(1) | 逻辑删除（0存在 2删除） |

```

DROP TABLE IF EXISTS supplier;
CREATE TABLE supplier (
  id            bigint(20)   NOT NULL AUTO_INCREMENT COMMENT '主键',
  supplier_name varchar(200) NOT NULL COMMENT '供应商名称',
  credit_code   varchar(50)  DEFAULT '' COMMENT '统一社会信用代码',
  contact_person varchar(50) DEFAULT '' COMMENT '联系人',
  contact_phone varchar(20)  DEFAULT '' COMMENT '联系电话',
  status        char(1)      DEFAULT '0' COMMENT '状态（0正常 1停用）',
  create_by     varchar(64)  DEFAULT '' COMMENT '创建者',
  create_time   datetime     DEFAULT NULL COMMENT '创建时间',
  update_by     varchar(64)  DEFAULT '' COMMENT '更新者',
  update_time   datetime     DEFAULT NULL COMMENT '更新时间',
  del_flag      char(1)      DEFAULT '0' COMMENT '删除标志（0存在 2删除）',
  PRIMARY KEY (id),
  KEY idx_supplier_name (supplier_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='供应商表';
```

**⭐ 注意加了 `KEY idx_supplier_name`**（索引），因为要按名称搜索。

import { listSupplier, delSupplier } from '@/api/supplier'
import EditDialog from './edit.vue'

export default {
  name: 'SupplierIndex',
  components: { EditDialog },

  data() {
    return {
      loading: true,
      showSearch: true,
      supplierList: [],
      total: 0,
      ids: [],
      single: true,
      multiple: true,
      queryParams: {
        pageNum: 1,
        pageSize: 10,
        supplierName: undefined,
        contactPerson: undefined
      }
    }
  },

  created() {
    this.getList()
  },

  methods: {
    getList() {
      this.loading = true
      listSupplier(this.queryParams).then(response => {
        this.supplierList = response.rows
        this.total = response.total
        this.loading = false
      })
    },

    handleQuery() {
      this.queryParams.pageNum = 1
      this.getList()
    },

    resetQuery() {
      this.resetForm('queryForm')
      this.handleQuery()
    },

    handleSelectionChange(selection) {
      this.ids = selection.map(item => item.id)
      this.single = selection.length !== 1
      this.multiple = !selection.length
    },

    handleAdd() {
      this.$refs.editDialog.open()
    },

    handleUpdate(row) {
      this.$refs.editDialog.open(row.id)
    },

    handleDelete(row) {
      const ids = row.id || this.ids
      this.$modal
        .confirm('是否确认删除选中的供应商？')
        .then(() => {
          this.loading = true
          return delSupplier(ids)
        })
        .then(() => {
          this.loading = false
          this.getList()
          this.$modal.msgSuccess('删除成功')
        })
        .finally(() => {
          this.loading = false
        })
    }
  }
}
</script>

        <el-input v-model="form.contactPhone" placeholder="请输入联系电话" maxlength="11" />

      <el-form-item label="状态" prop="status">
        <el-radio-group v-model="form.status">
          <el-radio label="0">正常</el-radio>
          <el-radio label="1">停用</el-radio>
        </el-radio-group>
      </el-form-item>
    </el-form>

    <div slot="footer">
      <el-button type="primary" @click="submitForm">确 定</el-button>
      <el-button @click="cancel">取 消</el-button>
    </div>
  </el-dialog>

<script>
import { getSupplier, addSupplier, updateSupplier } from '@/api/supplier'

export default {
  name: 'SupplierEdit',
  data() {
    return {
      visible: false,
      title: '',
      form: {},
      rules: {
        supplierName: [
          { required: true, message: '供应商名称不能为空', trigger: 'blur' },
          { max: 200, message: '不能超过200个字符', trigger: 'blur' }
        ],
        creditCode: [
          { required: true, message: '统一社会信用代码不能为空', trigger: 'blur' },
          { min: 18, max: 18, message: '必须是18位', trigger: 'blur' }
        ],
        contactPhone: [
          { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
        ]
      }
    }
  },
  methods: {
    open(id) {
      this.reset()
      this.visible = true
      if (id) {
        this.title = '修改供应商'
        getSupplier(id).then(response => {
          this.form = response.data
        })
      } else {
        this.title = '新增供应商'
      }
    },

    reset() {
      this.form = {
        id: undefined,
        supplierName: undefined,
        creditCode: undefined,
        contactPerson: undefined,
        contactPhone: undefined,
        status: '0'
      }
      this.$nextTick(() => {
        if (this.$refs.form) {
          this.$refs.form.resetFields()
        }
      })
    },

    cancel() {
      this.visible = false
      this.reset()
    },

    submitForm() {
      this.$refs.form.validate(valid => {
        if (!valid) return

        if (this.form.id) {
          updateSupplier(this.form).then(() => {
            this.$modal.msgSuccess('修改成功')
            this.visible = false
            this.$emit('ok')
          })
        } else {
          addSupplier(this.form).then(() => {
            this.$modal.msgSuccess('新增成功')
            this.visible = false
            this.$emit('ok')
          })
        }
      })
    }
  }
}
</script>

<details>
<summary>答案</summary>

1. **一个**（`public/index.html`）
2. ① import 依赖 ② 挂全局能力（组件/方法/插件）③ `new Vue()`
3. **`loadView`**
4. 因为 `loadView` 会拼成 `@/views/${component}`，webpack 自动补 `.vue`，写了会变成 `.vue.vue`
5. `{ ...to }` 复制只读的 `to`；`replace: true` 替换历史记录（防止后退循环）
6. **路由级**（`permission.js` + `filterDynamicRoutes`）、**菜单级**（后端筛选）、**按钮级**（`v-hasPermi`）
7. **后端硬编码**（`SysPermissionService` 里 `perms.add("*:*:*")`）
8. `R<T>` → **`data`**；`TableDataInfo` → **`rows`** + `total`
9. **`el.parentNode.removeChild(el)`**（从 DOM 彻底删除）
10. **不能**（改 DOM / 直接调接口都能绕过，后端 `@SaCheckPermission` 才是防线）
